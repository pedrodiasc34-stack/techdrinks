 🍻 TechDrinks

Sistema web para gerenciamento de pedidos de uma adega e distribuidora de bebidas, contando com interface para clientes realizarem pedidos e painel administrativo para controle do negócio.

 🚀 Funcionalidades

- **Área do Cliente:** Visualização do catálogo de bebidas, seleção de produtos e realização de pedidos.
- **Painel Administrativo:** Gerenciamento de produtos, acompanhamento de pedidos e controle operacional.

 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
